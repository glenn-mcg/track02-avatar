# AI Use Disclosure

## Overview

AI coding assistants were used during development of this assessment
project as development assistance.

The candidate remains responsible for understanding, reviewing, testing
and modifying all submitted code.

## Areas Where AI Assistance Was Used

AI assistance was used for:

- Drafting and refining Python implementation ideas.
- Reviewing error messages and debugging approaches.
- Suggesting test cases and edge cases.
- Reviewing CLI workflows and data flow.
- Helping identify missing engineering and reproducibility requirements.

## Human Review

Generated or suggested code was reviewed and tested locally before being
retained in the project.

The project was executed through the local CLI and tested using pytest.
Generation was also tested through the disclosed Kaggle execution route.

Material implementation decisions were reviewed by the candidate and can
be explained, modified and debugged independently.

## AI-Generated Content

AI assistance did not replace the project's execution, testing or evidence
collection.

Generation outputs, benchmark measurements, runtime information and
failure logs were produced from actual executions of the implemented
system.

No fabricated benchmark results or fabricated generation outputs were
used.

## Models and Services Used for Generation

The avatar-generation model used by the implementation is:

`stabilityai/stable-diffusion-xl-base-1.0`

Image inference was executed through the disclosed Kaggle free-compute
route using open/open-weight model software and weights.

No paid commercial image-generation API was used as the core generation
backend.

## Data and Privacy

The baseline avatar test set uses fictional synthetic subjects.

No personal photographs or non-consented identity data are used in the
 generation experiments.

## Candidate Responsibility

The candidate is responsible for the correctness, safety, licensing,
reproducibility and maintainability of the submitted implementation.
