# Sources and Third-Party Components

## 1. Stable Diffusion XL

- Model: `stabilityai/stable-diffusion-xl-base-1.0`
- Source: Hugging Face / Stability AI
- Used for: Human-avatar image generation
- Model type: Open/open-weight generative image model
- Revision used: `stabilityai/stable-diffusion-xl-base-1.0`
- Execution route: Kaggle free GPU notebook
- Commercial generation API: Not used

The model is loaded directly through the Diffusers pipeline. No paid
commercial image-generation API is used by the system.

## 2. Hugging Face Diffusers

- Package: `diffusers`
- Used for: Loading and executing the Stable Diffusion XL pipeline.
- License: See the package repository and installed package metadata.

## 3. PyTorch

- Package: `torch`
- Used for: Tensor computation and GPU inference.
- Execution: Local CPU environment for orchestration/tests and Kaggle GPU
  environment for image inference.
- License: See the official PyTorch repository and package metadata.

## 4. Kaggle

- Service: Kaggle Notebooks
- Used as: Free compute execution environment for SDXL inference.
- Product architecture: The local application remains responsible for
  job creation, orchestration, validation, evaluation and provenance.
- Kaggle is used only as the disclosed image-generation execution route.
- No paid compute or pay-as-you-go usage is enabled.

## 5. Python ecosystem

The project uses open-source Python packages for CLI functionality,
schema validation, image processing, testing and orchestration.

Exact package versions are recorded in the project's dependency/
environment files where applicable.
